# ISO Standards

## Countries
- CCA2 (ISO 3166-1 alpha-2)
  - 2 letters
- CCA3 (ISO 3166-1 alpha-3)
  - 3 letters
- CCN3 (ISO 3166-1 numeric)
  - 3 numbers
- CIOC (Olympic Code)
  - 3 letters
  - Defined by: International Olympic Committee

## Languages
- ISO 639-1
  - 2 letters
- ISO 639-2
  - 3 letters

## Currencies
- ISO 4217 alpha-3
  - 3 characters
- ISO 4217 numeric
  - 3 numbers
